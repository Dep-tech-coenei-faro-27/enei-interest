# ENEI Frontend

Frontend React/Vite da página de interesse do ENEI 2027.

## Instalação

```bash
npm install
```

## Desenvolvimento

```bash
npm run dev
```

## Configuração da API

Cria um ficheiro `.env` se quiseres alterar o backend usado pelo formulário:

```text
VITE_API_BASE_URL=http://localhost:8000
```

## Build

```bash
npm run build
```
